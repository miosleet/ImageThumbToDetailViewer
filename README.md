# 选片助手工作台（ImageThumbToDetailViewer）

面向拍摄图片审图流程的桌面工具：缩略图浏览、大图查看、批量选择，并把选中的图片批量复制 / 移动到文件夹或回收站，导出拼接缩略图，以及按格式 / 文件大小 / 分辨率转换选中的图片。支持RAW格式。

基于 **PySide6** 开发。

---

## 功能

### 浏览
- **打开文件夹**：列出该文件夹内所有支持的图片（仅当前文件夹，不递归子目录），按文件名排序。
- **缩略图网格**：以网格的形式展示缩略图。采用虚拟绘制，只画可视区域的格子；图片在后台线程按需读取，大文件夹也不会卡住界面。
- **缩放(Ctrl + 滚轮)**：逐档缩放，从约 10 列的密集网格缩略图显示，逐级放大到单图放大显示（最高约 4 倍），且维持缩放后光标所在图片仍然在光标下。
- **单图完整画质**：在每行 1 张（含放大）时，RAW 会在后台按完整分辨率重新解码并替换显示，保证大图清晰；

### 选择
- **单击**格子任意位置：勾选 / 取消勾选。
- **Shift + 单击**：范围选择（类似文件管理器）。
- **按文件名匹配(Enter)**：输入文件名或片段，用英文 / 中文逗号分隔。完整文件名优先匹配，其次按“包含”匹配；
  每个输入项最多匹配一个文件。匹配结果即成为当前勾选，手工勾选的内容也会同步回输入框。
- **全选(Ctrl + A)**：一键勾选当前文件夹中的所有图片。
- **全不选(Esc)**：取消所有勾选。

### 复制/移动/删除
- **复制到新筛选文件夹 / 移动到新筛选文件夹**：在当前文件夹旁新建 `筛选_XX`，编号取最小的未占用值。移动后会刷新缩略图网格。
- **复制到指定文件夹(Ctrl + C) / 移动到指定文件夹(Ctrl + X)**：复制或移动选中的图片到自选任意目标文件夹。使用系统原生的复制 / 移动，
  遇同名文件弹出系统自带的冲突对话框（替换 / 跳过 / 两者都保留）；若原生调用不可用，则退回内置冲突对话框（替换 / 全部替换 / 跳过 / 全部跳过）。
- **移动到回收站(Del/Backspace)**：先弹出确认框，确认后送入回收站。移动到回收站后会刷新缩略图网格。

### 导出拼接缩略图
- **导出拼接缩略图(Ctrl + S)**：把选中的图片按当前档位的一行列数拼接成一张大图（总宽 3840），每格为缩略图并带文件名，高度随行数自然增长；放大显示时维持单列。可导出为 PNG / JPEG

### 格式大小分辨率转换
- **格式大小分辨率转换**：把选中的一组图片统一转换为 JPG / PNG，并可同时调整分辨率与文件大小。
  - **目标格式**：可选 jpg / png，默认 jpg。
  - **分辨率**：仅选中 1 张图片时可调，两个输入框默认填入该图原始长宽。宽 / 高之间为“等比”勾选框，勾选后修改其一、另一项按原始比例同步变化；取消勾选后额外出现“缩放方式”一行：黑边填充 / 白边填充 / 拉伸 / 裁切，用于处理不等比缩放。选中多张图片时仅保留标题行，内容处提示“调整分辨率仅在选中1张图时可用”。
  - **文件大小**：手动输入上限（MB），转换后体积在小于该值的前提下尽量大（以调整过分辨率之后的图像判断）：JPG 通过品质逼近上限，PNG 为无损格式、体积仅由分辨率决定；留空则不做大小转换，按最高品质导出。
  - **输出文件**：可调整输出文件夹（默认当前所在文件夹），点击文件夹路径弹出选择窗口；仅选中 1 张图片时可修改文件名，后缀随目标格式固定不可改，默认按“原文件名 + 冲突序号”计算（无冲突为 `aaa`，已存在则 `aaa(1)`、`aaa(2)`…）。选中多张图片时仅可选文件夹、不显示文件名，命名沿用相同的自动避让逻辑。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| 滚轮 | 上下滚动 |
| 横向滚轮（若有） | 左右移动 |
| Ctrl + 鼠标滚轮 | 放大 / 缩小 |
| 单击格子 | 勾选 / 取消 |
| Shift + 单击 | 范围选择 |
| Ctrl + A | 全选 |
| Esc | 全不选 |
| Ctrl + S | 导出拼接缩略图 |
| Ctrl + C | 复制到指定文件夹 |
| Ctrl + X | 移动到指定文件夹 |
| Del / Backspace（退格） | 移动到回收站（图片视图聚焦时） |
| 输入框中按 Enter（回车） | 匹配文件名 |

---

## 支持的格式

- **普通图片**：JPG、JPEG、PNG、BMP、GIF、TIF、TIFF、WEBP
- **RAW**：ARW、CR2、CR3、NEF、NRW、DNG、RAF、RW2、ORF、PEF、SR2、SRF、3FR、ERF、KDC、MRW、 RAW、RWL、X3F、IIQ、MOS、MEF、ARI

---

## 运行环境

- **Windows**（原生复制 / 移动与回收站依赖 Windows 外壳）
- 源码运行需要 Python 3.10+
- 依赖库：`PySide6`、`Pillow`、`rawpy`

---

## 运行方式

### 源码运行
```bash
pip install PySide6 Pillow rawpy
python ImageThumbToDetailViewer_v3.py
```

### 已打包的单文件 exe
直接双击 `dist/ImageThumbToDetailViewer.exe`。采用窗口模式打包，**不会出现控制台黑框**。
